An offline, open-source guide and interactive tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. It provides a local checklist saved in your browser with complete JSON export and import options, category and grade filters, a spoiler setting that shields story trophy names and descriptions until earned, an organized roadmap to the platinum trophy, explicit missable flags, and an independently cited guide for every trophy. Please note that the $250 prize is competition-based and shared across 50 places on make.fun: only winners are paid, and no earnings are promised.

## Run it

```sh
# Serve the app locally, then open http://localhost:8080
node serve.ts

# Or package the distribution bundle
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
